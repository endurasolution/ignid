The Ignid source code is licensed under the [Apache License 2.0](LICENSE),
which gives you broad rights to use, modify, and redistribute it — including
commercially. That license does **not**, however, grant any rights to the
"Ignid" name or logo (Apache 2.0 Section 6 says this explicitly). This
document explains what that means in practice.

## What's protected

"IGNID", "IGNID PROGRAMMING LANGUAGE", "ENDURASOLUTION", and the Ignid logo
are trademarks of EnduraSolution.

## What you can freely do

- Fork the source code, modify it, and redistribute your modified version —
  the Apache 2.0 license already covers this.
- Give your fork or derivative its own distinct name.
- Truthfully describe your project as:
  - "Written in Ignid"
  - "Built using the Ignid Programming Language"
  - "Compatible with Ignid"
- Use the `.ig` file extension for programs written in Ignid — this policy
  claims no ownership over the file extension itself.
- Distribute, license, sell, or otherwise commercially use programs *you*
  write in Ignid, without any obligation back to this policy.

## What you can't do without permission

- Name a fork, derivative compiler, or competing product "Ignid" (or a
  confusingly similar name), or use the Ignid logo for it.
- Use the "Ignid" or "EnduraSolution" name or logo in a way that suggests
  your project is official, endorsed by, or affiliated with EnduraSolution
  when it isn't.
- Use the "Ignid" or "EnduraSolution" name to brand a different programming
  language, compiler, or product as if it were the original.

## Why this exists

The point is narrow: to stop a fork from confusing users into thinking it's
the official Ignid project. It doesn't restrict what you can do with the
*code* — that's entirely governed by the Apache 2.0 license, which is
already about as permissive as an open-source license gets.
